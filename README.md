# ML Lab 3 – Exploratory Data Analysis (EDA)

This repository contains the solution for Lab 3 of the ARTI308 course.

## Description
Exploratory Data Analysis (EDA) was applied on a chocolate sales dataset to understand patterns, trends, and relationships in the data.

## Steps Performed
- Data loading and inspection
- Checking missing values and duplicates
- Data type conversion
- Descriptive statistics
- Univariate analysis
- Revenue analysis by country, product, and sales person
- Correlation analysis
- Time-based revenue trends

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset
Chocolate sales dataset including:
- Sales Person
- Country
- Product
- Date
- Amount
- Boxes Shipped
